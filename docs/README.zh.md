## 文档维护

- 修改行为时同步更新对应专题；README 只保留概要和入口。
- 默认 `.md` 文件使用英文，同目录的 `.zh.md` 为中文版本；在同一变更中同步内容及验证状态。语言入口互相链接，各语言页面优先链接对应语言的文档；源代码、截图、命令和许可证引用保持原目标。
- 数据路径与凭据规则统一维护在「数据与凭据」，构建和检查命令统一维护在「开发与构建」。
- 区分已实现、已运行的验证和仍待验证的行为，不将测试命令存在等同于验证通过。
- 文档保留当前行为、必要的设计约束和可复现的验证入口。
- [README 展示图](screenshots/readme/README.zh.md) 使用独立 mock 数据，只用于界面展示，不作为连接、传输或性能验证的证据。
