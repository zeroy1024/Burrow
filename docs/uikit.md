# 公共 UI 组件迁移

本批以 `d534c5c` 为基线，完成基础适配、会话弹窗和设置页的组件抽取。沿用 Go 1.27.3、MyGo v0.7.3；组件每次构建读取当前主题。

## 第一批范围与依赖

`desktop → uikit → theme / MyGo`。`uikit` 不引用 `desktop`，不读取配置、不访问文件或网络、不操作钥匙串，不注册应用级订阅。

| 阶段 | 内容 | 页面侧保留的职责 |
| --- | --- | --- |
| 基础 | 颜色、多层阴影、主题映射、动效、Button/IconButton、文字/图标入口、Tooltip、Kbd、SearchField | 系统主题监听、快捷键绑定、稳定 Handle、页面导航 |
| 会话弹窗 | Input、PasswordInput、Select、Segmented、FormRow/FieldMessage、Modal、Section、Chip 外观 | 草稿、认证、端口规则、环境变量提交、校验、测试连接、保存和退出计时 |
| 设置页 | SettingsGroup/Row/NavItem、ThemeCard/SchemeCard、数字输入、Switch、Popover、密钥表单外观 | 搜索/高亮、本地化、偏好写入、字体/配色数据、密钥操作与生命周期 |

第一批完成时，SSH/文件工作区的导航与容器仍留在原处；第二批的接入范围见下文。`uiadapt.go` 中仍有消费者的入口只转发公共实现，全部调用方迁移后再删除这些入口。

## 控件与状态契约

- `Input` 返回真实的文本控件，`Changed`、`Submitted`、焦点、选区和 `Bind` 仍作用于输入本身。会话输入先处理本帧编辑与失焦校验，再调用一次 `StyleFormControl`，避免重复叠加阴影或延迟校验。
- `SearchField` 返回 `SearchParts{Root, Input}`，接受调用方的稳定 Handle。图标、快捷键提示逐层 `PassThrough`；整个外框属于文本输入。快捷键文案由页面当前绑定提供。
- 端口继续使用字符串保存编辑中间态；空值失焦恢复默认端口、手工修改标记和 FTP/TLS 端口切换留在会话控制器。
- 环境变量的 Enter、失焦提交和删除由页面控制；逗号是合法 VALUE 的组成部分。Chip 组件只构建显示与移除按钮，返回事件供调用方处理。
- `Modal` 只处理面板边界、遮罩和阴影。提交快捷键、退出动画、测试取消、凭据清理、保存与焦点交还仍沿用原流程。
- Settings 的过滤与高亮在页面完成。组件只渲染传入标题、内容和状态；关闭设置后的临时状态清理、稳定句柄复用、防抖保存与后台密钥任务保持应用级所有权。
- 主题卡、配色卡和强调色选择保留当前尺寸及图案。原生 Select/Switch 与会话表单的不同既有尺寸分别保留。

## 主题与动效

`tokens_src.py` 是唯一令牌源；`gen.py` 和 `mdgen.py` 生成 Go、JSON 与 Markdown。此次仅为 Kbd 补充实际使用的组件映射及语义角色，沿用已有 palette 值；Flat 提示保持原搜索框文字几何。

根视图每次构建设置 `uikit.UITheme`；`theme.OnChange` 的订阅仍只在应用生命周期注册。`Reduced` 接收现有 `system/on/off` 偏好，`Position` 保留非零瞬时时长；`Visual` 保留颜色与透明度过渡。没有新增页面切换动画。

## 后续阶段

数据表格、仪表、传输行等组件迁移前继续区分等价抽取、视觉调整和行为变化。复杂拖拽控制器继续由应用持有；后续只收敛预览、占位等纯显示部分。独立目录、三页互斥、全局连接/传输更新、原生菜单、宽度感知面包屑、常驻传输栏和拖动指针规则继续作为约束。

本批沿用现有测试、构建与静态检查，并复用隔离的状态和布局数据诊断；不新增永久测试、画廊、截图基线或视觉验收流程。

### 第二批保留的契约

- UIKit 返回原节点或 Parts，`Bind`、菜单、点击、Drag/Drop 仍挂在同一个交互节点。目录先执行 `trackCatalogDrag`，再根据当前状态构建样式与事件；没有改用 `TabsBase/ListState.Reorder` 接管拖拽。
- SiderRow 不接受连接状态或选中状态。普通单击只聚焦，双击/Enter打开；更多按钮继续使用 `FocusVisible`，默认背景透明。
- UI 连接枚举与应用枚举显式映射；标签内容在原构建时点读取最新连接状态。减少动态效果下仍显示静态指示。
- 标签与窗格拖动目标仍由 `paneDragHandle` 管理，默认箭头、实际起拖后闭合抓手。拖拽落点、取消、回位、停靠、重排与自动滚动控制器不变。
- 终端继续从各会话的配色和实际背景解析 surface，UIKit 不用全局 App 背景覆盖终端；滚动渐隐保留终端与文件面板不同的遮罩着色来源。
- PathBar 保留 `ShapeText/LayoutBounds` 实测宽度、保根与最近祖先的折叠算法、省略项对应的跳转目标和宽度变化后的重新布局；没有改成固定可见段数。
- 全局会话连接、分屏关闭、传输计时与设置保存的更新位置不变。容器的创建/卸载不负责创建、取消或重新连接会话与后台任务。
