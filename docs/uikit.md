# 共享 UI 组件

[internal/uikit](../internal/uikit/) 封装原生 MyGo 组件的外观、语义和 UI 状态，供桌面页面组合使用。业务工作由应用持有，不因组件挂载或卸载而创建、销毁。

## 组件入口

| 类别 | 主要文件 |
|---|---|
| 文字、图标、按钮、状态 | `text.go`、`icon.go`、`button.go`、`badge.go`、`spinner.go` |
| 容器与分区 | `card.go`、`section.go`、`divider.go` |
| 输入、选择、表单 | `input.go`、`select.go`、`multiselect.go`、`form.go`、`toggle.go`、`chipinput.go` |
| 弹窗、菜单与反馈 | `modal.go`、`popover.go`、`menu.go`、`tooltip.go`、`toast.go` |
| 导航与工作区 | `rail.go`、`sider.go`、`tabs.go`、`pane.go`、`sidepanel.go` |
| 文件与表格 | `table.go`、`sortheader.go`、`filepane.go`、`pathbar.go` |
| 终端、滚动与监控 | `terminalsurface.go`、`scrollbar.go`、`scrollfade.go`、`meter.go`、`sparkline.go` |

具体参数以对应文件中的 Props、状态类型和公开函数为准。设计令牌来源及生成方式见[主题与设计令牌](theme-integration.md)。

## 状态与输入

组件保存焦点、悬停、弹层开关、选择展示、显隐时间和测量等 UI 状态；应用保留配置、文件、网络、凭据和任务对象。

同一对象使用稳定 Key 和窗口生命周期内的稳定 Handle。排序和跨组移动应保持业务身份，取消原生拖放时清理实际手势状态，不能把动画恢复位移当作新拖动。

`Element` 只在当前构建 pass 中有效。退出副本会继续执行绘制回调，布局观察器应通过既有 `Handle` 在绘制时解析当前控件，控件已经卸载时停止观察，不捕获旧 `Element` 查询几何信息。

标题栏使用 SDK 的 `TitleBar` 左右预留量避让系统窗口按钮。`ShortcutDisplay` 统一渲染平台快捷键提示，动作继续使用 `ui.Cmd`（macOS Command，其他平台 Control），不按显示字符串判断按键。

弹窗、菜单和 Tooltip 组合 SDK 的原生语义与定位能力；快捷键提示与实际事件绑定分开。设置页的说明性提示不直接显示在页面中，统一通过 `SettingsLabel` 在分组标题或设置项名称右侧放置 `HelpTip` 问号：仅鼠标悬停显示 Tooltip，不响应点击、不获取焦点，提示文字同时作为图标名称供读屏使用（SDK 将未命名的图标视为装饰，不放进无障碍树）。显示当前值的小字（如强调色名称、许可证类型）仍保留在名称下方。关闭设置清理临时状态，同时保留需要复用的句柄。

`Modal.Disabled` 通过透明的模态输入遮挡层锁定整个弹窗，不叠加禁用态透明度；只需阻止关闭且保留内容交互时使用 `DismissDisabled`，例如一次性密钥展示期间仍须允许复制和勾选保存确认。应用保存配置等全局忙碌阶段也使用输入遮挡层，保留原画面。

`Modal` 统一拥有入场、退出和遮罩生命周期。用户取消走 `RequestDismiss`，未保存内容先确认；完成操作后走 `ModalParts.Close` 或 `ModalController.Close`，异步回调在 UI 线程请求关闭，并保留弹窗及其数据直到 `Dismissed`。淡出由遮罩父节点的 `AnimatePose.Fade` 带动面板，面板独立缩放，退出计时与动画使用同一时长；到期先移除整个浮层，再恢复焦点。模态动画中间帧由 SDK 重绘，不主动逐帧重建业务界面。

本地文件面板、路径与搜索栏、会话高级分区通过 SDK 的退出副本完成收起动画。退出内容立即离开鼠标、键盘和无障碍交互树，不使用 `Disabled` 叠加透明度；布局变换继续使用原有的宽度、位置和折叠动画。

传输列表折叠后同样只保留无交互的退出副本。分屏关闭使用 `AnimatePose` 淡出和缩放，到期才重建以移除窗格；密钥高亮与窗格模糊揭示由 `Painter` 的时钟推进，仅请求重绘。固定的“已复制”反馈只在显示期限结束时唤醒界面。应用级减少动态效果设置需传入控件的 `Motion`，拖拽取消动画也遵循同一策略。

`Select`、`MultiSelect` 和窗口内菜单统一在选项行末显示选中对勾。`MultiSelect` 从给定选项中多选，已选项在输入框内以可换行标签展示，标签尾部的关闭按钮移除该项；选项弹层允许连续选择，通过点击外部或 Esc 关闭。

下拉与普通菜单选项的悬停、键盘焦点高亮使用中性底色和正文文字色，选中状态通过行尾对勾表示；危险菜单项沿用危险色反馈。

`Text` 的样式覆盖页面所需的字号与字重组合，`Mono` 以相同字号切换等宽字体；页面优先选用这些样式与 `Tone`，不另行组合字号、字重和文字颜色。`IconTile` 统一图标方块的尺寸、圆角与底色，`SizeSm` 用于行内文字旁，默认用于列表行，`SizeLg` 用于标题旁。

`Inset` 是嵌入弹窗或卡片正文的带边框面板，如规则、任务和逐文件结果；`Tone` 以警告或失败底色区分状态，`Compact` 用于行。只读长文本使用 `CodeBlock`，提示信息使用 `Banner`，不另行拼装凹陷容器。`Disclosure` 用于面板与抽屉内的折叠分区，箭头随展开旋转，键盘焦点使用统一焦点阴影；弹窗内的分区使用 `Section`。

`Count` 的 `Max` 和 `Segmented` 的 `CountMax` 可限制计数展示；MCP 主标签页使用 99 上限，零值显示为 `0`，超出显示 `99+`，其他未配置上限的计数保留完整数字。

## 表格与滚动

文件 DataTable 基于真实 `ui.List(...).Rows(...)` 虚拟化，路径是选择、定位和源行保活的稳定身份。应用负责目录内容、排序与文件动作，共享 UI 负责显示和输入适配。

`TableViewport` 为 MCP 等自定义表格提供最小内容宽度与双向滚动。表头与数据内容共用视口宽度和最小宽度计算出的明确宽度，不在双向滚动容器内依赖百分比宽度，避免行内容变短后带动总宽度变化。筛选栏和表头保持在数据行上方，通过 `ScrollWith` 与数据行同步横移；分页栏放在视口外。表头与行内容使用相同的总内边距，避免展开详情压缩表格时列宽坍缩或错位。每张表只声明一组 `Column`：`TableHeaderRow` 由它绘制表头，行使用 `ListRow{Table: true}`，单元格使用 `TableCell`，列宽只写一次；多行单元格的行通过 `PaddingY` 随内容增高。`TableToolbar` 承载表头上方的筛选项。

侧栏与抽屉的宽度调整使用 `SidebarDivider`、`DrawerDivider` 和 `ResizeGutter`，共用拖动、方向键步进、范围限制和手柄显隐。传输面板与窗格分屏另有双击恢复、松手后保存和按比例调整等行为，各自处理输入，只复用手柄外观。

`Scrollbars` 装饰既有 Scroll/List，不替换滚动节点或业务状态。滚动条位于非滚动 frame，在其内容实际移动或鼠标贴边时显示；嵌套时外层不因指针下的滚动事件显示，只有 `Contain` 拦下的事件会唤起内层滚动条。内容未溢出时不绘制。MyGo 把每个滚轮事件交给指针下仍能移动的最内层容器，没有手势锁定，内层滚到边缘后同一手势（含惯性）会转去滚动外层；嵌在页面滚动内的有界滚动区通过 `Contain` 隔离：在该区域内开始滚动的手势到达纵向边缘后停在原处，从外部经过或在边缘新开始的手势仍交给外层。

`CodeBlock` 为完整文本提供有界的只读、选择和复制能力，每块内容只展示一组标题与复制按钮；调用方不重复添加同名标题。内部文本框通过 `TrackScroll` 接入共享 `Scrollbars`，隐藏 SDK 默认滚动条，沿用全局的宽度、颜色和显隐行为，并开启 `Contain`。SDK 文本框初建或文本变化时会把光标放到末尾并滚动到光标处，`CodeBlock` 在每段新文本出现时把光标移回开头，从首行显示。

会话标签栏保留滚轮横移、选择后定位和新增标签尾部加号定位，滚动条始终隐藏。快捷键设置按分组使用设置卡片行，随设置页自然滚动；`ShortcutField` 固定宽度并逐键显示键帽，使各行录制框和恢复按钮对齐。录制期间焦点离开该行（点击其他位置或其他控件）即取消录制。

真实 SSH 文字网格使用原生终端自身的滚动条；其他应用区域使用 UIKit 滚动条。两者的参数差异见[终端说明](terminal-themes.md)。

## 终端容器与栏下背景

`TerminalSurface` 接收会话配色及背景来源，`TerminalChrome` 适配周边 UI 对比度，`Pane` 承担容器与焦点展示；连接与终端对象继续由应用持有。

`ScrollFade` 提供栏内渐进模糊/着色，终端的 `ViewportBackdrop` 和文件表格的 `TableBackdrop` 提供实际相邻内容。显示用背景不拥有第二组交互或读屏行，不通过扩大真实输入视口改变业务网格。

MyGo 固定版本的静止 GPU 路径只保留最内层裁剪的圆角形状。终端补画先按网格边界限定范围，再在最内层应用完整卡片圆角；避免后加矩形裁剪覆盖圆角。
