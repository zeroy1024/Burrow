## 文档维护

- 修改行为时同步更新对应专题；README 只保留概要和入口。
- 数据路径与凭据规则统一维护在「数据与凭据」，构建和检查命令统一维护在「开发与构建」。
- 区分已实现、已运行的验证和仍待验证的行为，不将测试命令存在等同于验证通过。
- 阶段过程和旧设计进入[历史归档](archive/README.md)，不继续叠加到当前使用说明中。
- [既有截图](screenshots/session-settings/README.md) 是历史软件渲染样本，不是当前版本的原生窗口基线。
