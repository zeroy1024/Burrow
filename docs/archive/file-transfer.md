# 文件传输后端

页面继续使用既有 UIKit 文件卡片、DataTable、工具栏和底部队列。`file_connections.go`、`file_actions.go` 和 `internal/fileclient` 提供真实 I/O；UIKit 不持有网络、文件、持久化或钥匙串业务。

## 连接和目录

- 本地使用 `NewLocal()`；路径以 `filepath` 处理，`~` 展开为用户目录。
- SFTP 使用已认证 SSH transport 的独立 subsystem；FTP 每个浏览/任务使用独立控制连接。
- `Client` 提供 `InitialPath/ReadDir/Stat/OpenRead/OpenWrite/Mkdir/Rename/Remove/Done/Close`；Stat 为 Lstat 语义。
- 不扩大主`Client`接口；可选`PermissionSetter`、`DirectoryResolver`、`TreeRemover`分别提供权限设置、用户显式目录链接浏览及本地安全递归删除。文件链接仅`ErrNotDirectory`转原元数据预览，权限/连接错误照常报告。
- FTP优先MLSD，回退LIST -a并用NLST原始名称核对；前导/尾部空格和Tab不擅自裁剪，无法消除名称歧义时明确拒绝猜测路径。Unix LIST及MLSD可用Unix事实用于权限/所有者显示和实际权限保留。
- Unix LIST可浏览FIFO、socket、块设备和字符设备，保留真实类型与权限；设备的major/minor列不影响原始文件名。特殊文件内容传输和普通文件覆盖特殊目标均明确拒绝，续传及提交检查同样核对已知类型。
- 每个浏览视图串行读取目录，快速后续导航替换待执行目的地；成功后才提交路径/历史，错误通过现有提示显示。选择和定位仍使用完整路径作为稳定身份。
- 文件行按下后即登记手势源。源目录的异步响应与所属连接的断连通知在真实释放后发布，期间保留源行并拒绝取消状态的Drop；目录、断连发布与用户待处理动作独立保留。
- 浏览标签显式重连可以采用已保存的新配置；已有任务使用独立端点、连接组及认证版本快照，不被改向。
- 编辑初始本地或远程目录后，已有标签显式重连会应用变更；初始目录未改动时保留当前浏览路径和历史。

## 传输与一致性

`transfer_backend.go` 持有任务清单和 worker；`ftp_transfers.go` 保留原队列 UI。任务上下文来自应用，不来自页面或浏览视图。

1. 真实递归 Stat/ReadDir 生成清单和总字节；空文件总量为零，不伪造字节。
2. 冲突在实际目标 Stat 后决定；询问、覆盖、跳过、保留两者对嵌套子项也生效；apply-all覆盖同批多任务及已等待冲突。取消冲突时终止同批未完成任务，已完成文件不回滚，其他批次继续。目录覆盖为逐子项合并，文件/目录类型不匹配不能直接覆盖。
3. 相同或父子重叠目标在应用内互斥，本地锁对大小写及Unicode规范等价作保守协调。写任务独有随机 `.part`，流 Close 和最终 Rename 都成功后才标记完成。
4. 暂停中止本次I/O，保留清单、部分文件和已确认偏移/摘要检查点；继续校验源基线及目标part前缀，再从源offset读取，不重拉远端源前缀。v1/v2旧part首次对照源/目标前缀后建立v3检查点；不匹配或无法核对时明确失败。取消只清理该任务拥有的部分文件，已提交子项保留；清理失败可重试。
5. FTP REST 不支持、SFTP 标准 Rename 不支持替换等情况明确失败，不先删除原目标。获得覆盖授权时，SFTP 有 posix-rename 扩展则使用它；无覆盖授权时用标准 Rename，本地使用平台原子 NoReplace。FTP 本身没有条件重命名，只能预检，不能承诺隔绝外部并发写入。
6. 关闭浏览标签、切换 SSH/文件/设置不取消任务；完成不弹 toast。上传定位回到匹配目标视图，下载定位通过系统文件管理器显示真实文件。

符号链接传输拒绝并报告；递归不跟随链接。服务器返回的文件名和配置中的路径在实际边界验证。协议不能提供跨外部客户端事务锁，提交前会复核目标元数据，不能保证阻止其他程序在最终原子操作前后的并发修改。

用户可以显式进入目录链接；这不改变传输Lstat与拒绝链接的合同。darwin/linux本地文件打开使用锚定父FD、最终段NOFOLLOW、新建EXCL及打开后身份检查，校验后才截断；递归删除在固定目录FD下遍历并检查context，链接只unlink。覆盖既有文件在最终Rename前恢复并确认真实已知权限，不支持或未报告权限时拒绝覆盖；新目标不强制CHMOD，本地stage默认0600。

下载及其取消清理在每次执行期间持有选定目标目录的`os.Root`，Stat、创建、权限修改、提交和清理均从该句柄解析相对路径。子目录在传输或冲突等待期间被替换为指向树外的链接时，后续操作会失败，不会重新按绝对父路径写入树外。

上传同样在认证及冲突等待前固定本地源：目录任务锚定所选目录，单文件任务锚定其父目录并核验文件身份，拒绝将源符号链接作为传输根。构造时校验实际打开的对象与初始Lstat一致；后续遍历和读取都受该Root约束。取消上传只清理远端part，不要求本地源仍然存在。

FTP目录拼写存在大小写或Unicode等价候选时，先向服务器查询实际目标路径，再决定是否冲突；不会把所有服务器都当作大小写不敏感。服务器无法确认或返回歧义时明确失败，FTP仍不具备跨其他客户端的原子条件重命名。

上传覆盖受限读取权限的已有文件时，SFTP用带`0600`权限属性的独占OPEN原子创建stage，校验后才写入；继续旧part时先收紧并核验其权限。固定`pkg/sftp v1.13.12`仅通过本地扩展增加此创建参数，原接口保持原行为。FTP无法提供同等私有stage能力时，在发送文件内容前拒绝此类覆盖；已有目标权限未知也会提前报错。新目标和公开目标保留既有创建策略。

## 退出与恢复

正常退出先禁用新操作，暂停活动任务并等待 worker 归还清单，再原子保存 `transfers.json`。格式包含无秘密的端点/跳板快照、源基线、清单、已提交子项、冲突策略及部分文件所有权。密码仅由系统钥匙串按版本读取；版本已换则询问旧目标的密码，不把新目标的密码发送给旧任务。

FTP认证成功后的运行时密码缓存仅在捕获的认证快照仍有效时发布；连接过程中清除保存密码不会被晚到的成功结果撤销。

FTP连接错误返回前会隐藏本次提交密码的字面回显，正式连接与后台任务不会把该回显写入队列错误文本；错误链仍保留类型供分类。跳板依赖保护包含可重新打开的关闭标签；删除主机前刷新待保存工作区，写盘失败同时恢复原快照，避免成功发布引用已删除跳板的目录配置。

任务归属于具体文件标签，使用独立于站点配置ID的稳定身份。列表、计数、速度、全部暂停/继续、清除已完成、失败提示和冲突选择都按当前标签隔离；同一站点新开的标签也从空队列开始。没有文件标签时保留空传输栏；已有标签即使离线也显示自己的任务。切页、切标签或关闭浏览标签不取消独立后台worker；显式重新打开刚关闭的标签复用原对象和任务归属，定位到其他目标浏览器不会迁移任务。

工作区v2保存文件标签身份，队列v4保存所属标签引用。只有开启“启动时恢复会话”且原标签实际恢复，任务才绑定回该标签，离线即可显示；恢复过程不自动连接或继续。关闭该开关时不绑定旧任务，新建标签使用全新身份。已完成记录只为可恢复的原标签保存；未完成的检查点仍保留，避免丢失部分文件的归属。兼容旧工作区及v1/v2/v3队列；旧队列没有标签身份时只保留未完成检查点，不按主机名或地址猜测归属，因而不会混入任何新标签。

存在未关联打开标签的任务时，传输栏显示“找回任务”。点击后按原标签身份重新打开离线标签；本次运行内已关闭的标签复用原对象，缺少标签身份的旧记录按各自任务会话恢复。恢复只重新关联任务并展开列表，不自动连接或继续传输，各任务仍使用原端点和凭据版本。用户可在恢复的标签中继续任务或取消并清理部分文件；新建同站点标签仍从空队列开始。

恢复严格检查格式、标签身份、父子路径和部分文件派生名，未完成任务恢复为离线暂停，失败/已完成保留原状态，不自动连接。队列v4沿用v3的同批策略、提交状态、已确认偏移和摘要，不保存SHA内部状态或文件字节。取消/断网导致重命名结果不确定时，先核对暂存与最终目标及SHA-256；目标不可核实时明确保留不确定错误，不擅自重传。继续目录任务也核对已完成子项仍存在，避免缺失文件却显示整目录完成。配置读取失败不覆盖原文件；保存失败保留应用和暂停任务，显示真实错误。异常崩溃不具备逐笔日志保证。

## 协议与验证

FTP支持 plain/explicit/implicit TLS × passive/active，TLS强制证书验证，数据端 peer 受控制连接约束；UTF-8、GBK、GB18030、Big5、Shift_JIS、EUC-KR、ISO-8859-1 只转换文件名。服务器能力拒绝、编码不可表示或畸形列表均报告错误。
