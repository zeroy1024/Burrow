# SFTP / FTP 文件传输原型

文件传输入口现已开放，以 `SSH-Tool-FTP-v3` 的原生界面方案为基础，传输队列按后续要求改为始终在文件页最底部显示。用户确认本次延续项目的演示数据范围，不接入真实 SSH / FTP 认证或网络传输，不新增第三方依赖。文件操作只修改内存目录；从 Finder 选择或拖入时仅读取元数据。

## 结构与状态

- SSH 和文件页共用 `catalogList` / `catalogHostRow`、分组、搜索及目录拖拽，左侧图标由 `catalogHostIcon` 根据页面提供。共享目录的编辑与删除会影响两个页面，删除对话框明确说明这一点。SSH 保留原有单击新建独立会话行为；文件页单击已有站点切换到对应文件标签，无标签时创建演示连接。
- 连接状态统一使用固定 10px 状态槽。转圈在 Painter 内调度，仅被实际绘制时请求帧；减少动态时改为静止警告点。断开与失败页面保留重连入口，底部传输队列仍然可见。
- 本地抽屉由同一个 `AnimateTo` 弹簧值驱动，固定内层宽度、外层 `ClipX`，远程左缘随进度位移。列是否精简按最终宽度判断。减少动态时立即更新几何，通过 `AnimateColor` 的 alpha 适配保留淡入淡出；收起的本地卡临时绘制在远程卡上方以显示淡出。启动恢复直接到目标布局。
- 8px 分隔缝使用 `Dragged`、双击和方向键调宽，窗口最小尺寸随文件分栏同步更新，本地与远程分别至少 320 / 420px。焦点通过标签胶囊与选中行表达，文件卡关闭原生焦点环。
- 本地和远程卡片的顶部、底部模糊与渐变只绘制在各自栏高度内，不向文件列表延伸。底部传输卡片上方的 8px 空隙支持上下拖动调高，悬停显示水平抓手；双击恢复默认高度，上下方向键微调，折叠保留展开高度。调高时至少保留一行传输和一行文件的空间。
- 演示目录支持历史、面包屑、搜索、名称 / 大小 / 时间排序、多选和键盘导航；文件仅以列表显示，表头始终可见。右键提供上传 / 下载、新建、重命名、删除及复制路径。文件夹拖放优先于整卡，悬停 500ms 进入；根目录等演示只读路径不入队。
- 窄栏搜索在标题栏内用 `AnimateTo` 平滑展开、收起，并与面包屑淡入淡出；展开请求输入焦点，收起清空过滤并将焦点交回文件面板。宽栏与窄栏共用输入构造器，去掉默认垂直内边距，使用固定行高让文字和占位文字垂直居中。文件页仅保留列表，已移除网格及视图切换入口。
- 传输面板始终位于文件页最底部，无任务时显示空态，支持折叠与分类；任务完成后保留到用户清除。队列仅在 UI 线程按 `Context.Now` 推进，默认并发 3，较小文件保留可操作的演示时长。完成后更新目标演示目录，定位时清除搜索条件并选择目标。断开的任务转为明确失败，可重连后重试。
- `files.json` 保存本地面板展开状态、分栏比例、每站点本地路径，以及传输面板折叠、分类和高度偏好，包括 `transferDockHeight`（0 / 省略表示按任务数量使用默认高度）；复用现有原子配置写入，读取失败时阻止覆盖。目录内容、选中、滚动和任务保留在本次进程内的对应会话。

## 原生 API 与设计差异

实现核对项目固定的 MyGo v0.7.3 文档与源码（模块缓存中的 `docs/ui`、`docs/plugins/glass.md`），线上 Markdown 文档访问返回 403，因此以随依赖分发的相同版本文档为准。

| 需求 | 实际 API / 差异 |
| --- | --- |
| 本地开关、抽屉与调宽 | `ToggleBase`、`AnimateTo`、`Settled`、`ClipX`、`Dragged`；未对本地卡应用 Size 过渡。 |
| 文件列表 | 原生 `Scroll` + 行，固定显示列头；文件仅以列表显示，保持焦点、拖放与玻璃栏外观。 |
| 历史与面包屑 | 使用原生按钮组合历史与面包屑；按地址栏实际宽度及相同字体的文字测量值决定是否省略，空间足够显示完整路径，不足时保留根和尽可能多的尾部路径段。超长文字允许行内省略；窗口、分栏和搜索动画改变宽度后重新计算。内置 `BackButton` / `ForwardButton` 绑定 `ui.Router`，文件目录使用自身历史。 |
| 面板间拖放 | `Drag`、`DragOver[fileDrag]`、`Drop[fileDrag]`，沿用原生边缘自动滚动和 Esc 取消。拖动副本使用原生行快照，尚非设计稿中的紧凑多层叠卡 ghost；来源行使用 token 透明度。 |
| Finder 拖入 | `DroppedFiles` / `FileDragOver`，只创建演示任务。未实现可选的 Finder → 本地复制，也未提供远程 → Finder 的实际文件，因为不存在下载后的真实文件。 |
| 文件栏玻璃 | `glass.Blur` 与主题 tint；顶部、底部效果限定在各自栏高度内。`glass.Blur` 无单独 Saturate 参数，尚未叠加自定义饱和度着色器。 |
| 底部面板折叠 | 原生固定高度容器 + `AnimateTo` / Clip；`CollapsibleBase` 的内置时长不可配置，改用 token 驱动保持 300ms 弹簧。 |
| 传输显示 | 进度列宽 180px，进度、速度和状态列保持固定宽度，操作区统一预留两个按钮并靠右对齐，避免任务状态与按钮数量改变时错位。进度和徽章使用原生基础元素与 `C.Progress` / `C.Badge` 主题；面板宽度小于 720px 时使用紧凑传输行，标题隐藏速度摘要。 |
| 设计数据 | 复用仓库已有站点、字体与主题；文件名、日期、字节数和任务状态是演示数据，不把设计稿的固定进度 / 容量当作真实系统指标。 |

## 主题

文件页使用 `ProtocolIcon`、`PaneToggle`、`FilePaneFocus`、`FTPSplit`、`TransferDock`、`TransferRow`、`FilePane`，并扩展 `Tab`；danger、协议色、尺寸和动画从 semantic 派生，原始新增值放在 palette。原设计的 `TransferCapsule`、`TransferPopover` 及相关浮层阴影、自动隐藏 token 暂留作设计资料，对应 UI 和自动隐藏行为已移除。`ConnectionIndicator` 保留终端现有状态点视觉，避免继续引用已停用的侧栏 token。

原侧栏的选中 / 状态及 OS logo 选中 token 已标 deprecated 并保留生成。界面不再引用这些字段。`tokens_src.py`、生成器、`theme.go`、`tokens.json`、`tokens.md` 同步；推导值标记 derived。终端正文、渲染与 SSH 分屏交互保持原实现。
