页面文案使用以下统一约定，保持现有布局与授权模型：

- 功能入口使用“授权密钥”，字段和操作使用“密钥”；分类使用“命令策略 / 文件策略”，路径位置使用“本地 / 远端”。
- 同类文案使用等长句式：三段标题为“密钥名称 / 连接授权 / 目录授权”，操作按钮为“新增密钥 / 新增策略”“生成密钥 / 保存密钥”“复制密钥 / 复制配置”。
- 上传与下载卡片使用“上传来源目录 / 下载目标目录”“尚未添加上传目录 / 尚未添加下载目录”，说明使用“允许从目录及其子目录上传，仍受文件策略限制。”与“允许向目录及其子目录下载，仍受文件策略限制。”。
- 权限矩阵使用“文件读取 / 文件写入 / 命令执行”，启停状态使用“已启用 / 已停用 / 已撤销”。命令与文件编辑区分别使用“命令拦截规则 / 文件拦截规则”。
- 匹配方式使用紧凑下拉，直接显示“命令匹配 / 精确匹配 / 正则匹配 / 模糊匹配”，不重复添加“匹配”前缀。
- 面向用户的说明表达实际用途与影响，不展示固定目录句柄、摘要算法或暂存扩展名等实现细节；协议字段、请求响应正文保持原样。

## 1. 产品背景与设计范围

Burrow 是原生 SSH 与 SFTP / FTP / FTPS 文件传输桌面应用。本功能让本机 AI agent 通过 MCP 使用用户明确授权的连接、命令执行和文件能力；用户在 Burrow 中管理 Secret Key、拦截策略、审计和后台任务。

设计沿用现有桌面应用的主题、字体、间距、导航、表格、表单和弹窗约定，覆盖明暗主题、键盘焦点和可读的长命令 / 路径展示。设计范围是 MCP 独立页面及其关联表单、详情和状态。

第一版包含服务启停、Key 管理与授权、SSH / 文件拦截策略、审计、读取、单次命令、文本写入和上传下载。重命名、移动、删除、独立新建目录、交互式 Shell 与长命令后台任务属于后续工具能力；相关策略类型可以提前配置，但必须明确标注生效范围。

## 2. 页面入口与信息结构

- 最左侧导航栏新增 MCP 图标，位于文件传输入口之后、底部设置之前，与 SSH、文件传输同级。
- 选中 MCP 后进入独立页面，保留左侧全局导航，**不使用左侧 sider 会话侧栏，隐藏顶部 session tabs**，内容卡片直接占满工作区宽度，为表格和右侧抽屉留出充足横向空间。
- 标题栏仅保留窗口拖拽区域，不展示 MCP 标题、次级介绍文字或右上角“更多”菜单。
- 页面顶部是共享服务区，下方三个标签页依次为：**授权密钥｜拦截策略｜审计记录**。
- 三个标签均展示数量，最小显示 `0`，超过 99 时显示 `99+`。
- 所有 Key 名称均使用纯文本展示，覆盖授权密钥列表、审计列表与操作详情，不添加头像或首字母徽标。
- 点击审计记录从右侧滑出详情抽屉，左侧主列表保持原地可连续翻看；新增 / 编辑 Key 采用三段式模态框。策略行单击仅选中，通过右键或行尾“更多”展开菜单，再选择“编辑策略”打开模态框；新增策略仍使用模态框，列表保持全宽。
- 审计列表和详情之间提供可左右拖动的分隔条，支持键盘调整，限制两侧最小可用宽度；调整后的详情宽度在当前应用运行期间保留。
- 审计详情展开和收起沿用应用侧栏的过渡时长，列表平滑调整可用宽度；动画期间详情保持完整内容宽度并裁剪展示，避免文字反复换行。拖拽调宽直接跟随指针，开启“减少动态效果”时跳过位移动画。
- Key、策略和审计表格保持最小内容宽度；详情展开或窗口变窄时横向滚动，筛选栏、表头和数据列同步横移，分页栏固定在视口外，不能把摘要列挤成竖排。
- 无需单独增加任务标签页、命令输入终端或文件浏览工作区。

```text
左侧全局导航             MCP 页面
SSH                    服务开关 · 状态 · 本机地址 · 复制接入模板
SFTP / FTP             授权密钥 | 拦截策略 | 审计记录
MCP                    当前标签页的筛选、列表和管理操作
…                      按需打开表单或详情
设置
```

切换标签页、切换业务页面或隐藏窗口不会停止服务与后台任务。页面显示的是应用级服务和任务的真实状态。

## 3. 顶部服务区

| 功能 | 展示与交互 |
|---|---|
| 服务启停 | 开启 / 关闭 MCP 服务；停止处理期间显示实际状态 |
| 运行状态 | 未开启、启动中、运行中、停止中、故障；不能只根据开关位置显示成功 |
| 监听地址 | 展示配置的 Host / Port，默认 `127.0.0.1:7801`，支持复制；IPv6 使用带方括号的地址格式 |
| 监听配置 | 服务区右侧的编辑图标打开模态框，可分别配置 Host 和 Port；保存后同步更新地址显示与客户端配置模板 |
| 接入模板 | 查看、复制客户端配置模板；Key 使用占位符或目标客户端支持的环境变量引用 |
| 故障提示 | 端口占用、监听失败、审计不可写、Key / 授权 / 策略变更未保存等明确原因 |

顶部服务卡片布局约定：

- **左侧**：服务开关 + `MCP 服务` 标题 + 状态胶囊（未开启灰、运行中绿、停止中黄、故障红）。
- **中间**：监听地址可复制胶囊（如 `127.0.0.1:7801`）+ 运行时长、启用 Key 数、启用拦截策略数、今日调用数、今日拦截数。
- **右侧**：使用公共 IconButton 显示“复制客户端配置”和“编辑监听配置”两个图标按钮，悬停时提供用途提示。
- **状态反馈**：服务关闭时展示后台任务已暂停的提示。真实监听或存储故障反馈在后端接入时按实际结果实现；UI 阶段不提供故障预览、容量预警预览或重置演示数据入口。

监听配置弹窗包含 Host 输入与 Port 输入，端口范围为 1–65535，Host 不接受空值、URL、路径或附带端口的主机名。取消不改变当前配置，保存后地址胶囊和复制出的 `/mcp` URL 使用同一配置来源。

## 4. 授权密钥标签页

### 列表

| 字段 | 内容 |
|---|---|
| 名称 | 用户可辨认的 agent / client 用途名称 |
| Key 标识 | 公开前缀或短 ID，不能用于认证 |
| 状态 | 已启用、已停用、已撤销 |
| 权限摘要 | 获准连接与能力，必要时进入编辑查看完整配置 |
| 创建时间 | Key 创建时间 |
| 最近使用 | 最近通过认证的使用时间；尚未使用时明确显示 |
| 操作 | 编辑密钥、停用密钥（已停用时为启用密钥）、撤销密钥 |

列表右上角提供「`+ 新增密钥`」按钮。每行行尾提供悬浮显示的 `•••` 菜单（与 sider 条目做法一致），菜单文案为“编辑密钥”“停用密钥”“撤销密钥”；已停用时第二项改为“启用密钥”。撤销仍为永久操作，在确认弹窗说明不可恢复。**已撤销的 Key 整行置灰并固定排在列表最后**。第一版通过撤销保留身份与审计，不提供连带删除历史的操作。

### 新增与编辑授权

采用与新建连接同一套模态框，固定分为三段：

1. **第 1 段 · 密钥名称**：填写密钥名称（如 `claude-desktop`），提示每个客户端使用独立密钥。
2. **第 2 段 · 连接授权**：每个已保存连接一行，右侧排布 **文件读取、文件写入、命令执行** 三个开关（对应 `files.read`、`files.write`、`ssh.exec`；按连接协议开放可用项，例如 SSH 连接仅开放命令开关，SFTP/FTP 站点仅开放读/写开关）。
3. **第 3 段 · 目录授权**：左右并列「上传来源目录」和「下载目标目录」两个本地目录列表，支持添加与移除目录。

- 默认没有连接与能力授权，不能因选择连接就暗中勾选全部权限。
- 明确说明：Key 允许能力仍受拦截策略约束；策略不能扩大 Key 权限。

Key 中的文件读取 / 写入是能力授权；浏览、创建、重命名等更细类型在拦截策略中选择“禁止操作”，两处文案不能混淆。

### 创建成功与状态变更

- **创建成功（模态框内切换视图）**：在同一个模态框内展示仅显示一次的密钥明文、复制按钮、客户端配置模板预览及黄色警示，**必须勾选「我已复制并妥善保存密钥」后才允许点击「完成并关闭」**。
- 关闭后不提供明文再次查看；列表、编辑和审计不出现完整 Key。
- 丢失时新建并撤销旧 Key，不提供找回密钥。
- **停用 / 撤销确认弹窗**：使用确认弹窗写明具体影响（拒绝新调用、取消 `N` 个排队任务并请求取消执行中操作，历史审计保留）；永久撤销按钮使用危险色。
- 重新启用不会自动重启原任务。
- 保存失败时保留编辑内容并说明未保存，不能用成功提示替代实际结果。

## 5. 拦截策略标签页

### 列表与分类

分类文案统一使用「命令策略 / 文件策略」，可通过分类切换或筛选管理。列表同时支持按状态、适用连接和 Key 筛选。

编辑弹窗的分类选项显示为「命令策略 / 文件策略」，下方仅显示当前分类对应的规则编辑区与说明。

| 字段 | 内容 |
|---|---|
| 名称与说明 | 策略用途 |
| 分类 | 命令策略 / 文件策略 |
| 状态 | 启用 / 停用 |
| 适用连接 | 多选输入；留空为当前分类的全部连接，包含后续新增连接 |
| 适用密钥 | 多选输入；留空为全部授权密钥，包含后续新增密钥 |
| 规则摘要 | 命令匹配条件，或受保护路径及禁止操作 |
| 操作 | 新增；行菜单为编辑策略、停用策略（已停用时为启用策略）、命中审计、删除策略 |

“删除策略”使用危险色，并在确认弹窗说明删除后不再参与拦截且不可恢复；历史命中审计与当时的规则快照保留。

启用、停用只改变状态并独立记录审计，列表规则版本保持不变；编辑保存策略内容时才递增版本。

页面说明核心规则：**Key 已授权，并且没有命中任何启用的拒绝策略，才允许执行。** 首版没有允许规则、优先级和临时绕过按钮。

### 通用策略表单

新增和编辑策略复用公共模态框，展示策略名称、版本和表单内容，底部固定“取消 / 保存策略”。保存后更新版本，启用后参与拦截。表单过长时内部纵向滚动。保存成功后关闭弹窗，校验失败时保留表单并显示错误；关闭按钮、Esc 和取消均使用现有模态框关闭行为。

- 策略名称、说明、启用状态。
- 分类：命令策略 / 文件策略。
- 适用连接与适用密钥均直接使用多选 Select Input，不增加“全部 / 指定”切换；空值明确显示全部范围，包含后续新增的匹配项。
- 适用连接按分类提供兼容连接；切换协议分类时清除原类别的连接选择，回到新分类的全部连接范围。
- 两种多选输入框均在框内用标签展示已选项，标签尾部提供 X 移除；下拉内可连续选择，选中项在行末显示对勾。
- 普通 Select、筛选胶囊和多选下拉的选中标记统一放在选项行末，不使用行首圆点。
- 一条或多条分类规则，支持添加、编辑和移除表单内规则。
- 保存时只保留所选分类的规则；列表摘要与数量仅统计当前分类。历史混合数据在重新保存时清理非当前分类规则。
- 编辑中的草稿不生效，完整保存成功后生效；校验或保存失败要定位字段并保留草稿。

### SSH 命令规则

每条规则包含：

- 匹配方式：命令匹配（新建默认）/ 精确匹配 / 正则匹配 / 模糊匹配；命令匹配下方提供“参数忽略大小写”勾选项。
- 匹配内容，适合输入长命令或表达式。
- 固定动作：命中后拒绝执行。
- 正则错误、命令规则无法解析、空规则或超限内容的行内校验提示；模糊匹配规则显示可能误报、建议改用命令匹配的警示，策略列表规则摘要同样标注“含模糊匹配”。

命令匹配按解析出的实际调用比较命令名和参数，能识别组合命令与 sudo、bash -c、ssh 等写法；精确匹配针对完整提交命令；模糊匹配按区分大小写的字面文本包含判定；正则匹配按表达式判定。辅助说明应准确表达“防误操作”，说明无法解析时按关键词从严拦截、不检查脚本文件与解释器内部操作，不宣称理解全部 Shell 行为或提供完整安全隔离。规则编辑不提供实际执行命令的验证按钮。

各条命令规则的匹配方式下拉使用统一宽度，保证命令输入框左侧对齐。策略列表中的状态 badge 按内容自然收缩，保留公共组件默认内边距，不拉伸铺满状态列。

### 文件操作规则

每条路径规则可独立选择禁止操作，不能让所有路径共用一个无法分别配置的权限开关。

| 字段 | 内容 |
|---|---|
| 路径位置 | 远端 / 本地，明确区分两侧路径 |
| 目标类型 | 文件 / 目录 |
| 路径 | 明确的文件或目录路径；长路径可完整查看 |
| 包含子目录 | 仅目录类型显示；未勾选时仍匹配目录本身 |
| 禁止操作 | 多选浏览、读取、创建、写入、重命名、移动、删除 |

操作说明：

| 类型 | 说明 |
|---|---|
| 浏览 | 列目录、查看元数据 |
| 读取 | 文件内容读取；上传本地来源或下载远端来源 |
| 创建 | 新目标文件或目录；创建文件第一版可生效，独立新建目录工具后续上线 |
| 写入 | 修改、上传 / 下载覆盖、文本替换已有文件 |
| 重命名 | 同目录改名；对应工具后续上线 |
| 移动 | 跨目录改变位置；对应工具后续上线 |
| 删除 | 删除文件或目录；对应工具后续上线 |

本地规则仅约束 MCP 上传下载涉及的本地文件，不等于授权整个本机，也不影响用户直接使用桌面文件页。远端规则作用于指定文件连接。

表单或详情中的必要说明：重命名 / 移动会检查源和目标；目录任务逐项检查；文件策略不能约束任意 SSH 命令直接访问文件。无法核实路径边界时显示明确失败，不能提示为“已安全通过”。

### 策略变更状态

- 保存、启用或收紧规则后对新动作生效，受影响任务请求收敛；已经发生的操作不能回滚。
- 停用或放宽规则不会自动继续被拦任务。
- 策略持久化失败时明确“未保存”；收紧失败会关闭服务并显示故障。
- 不提供由 agent 自行确认放行的交互，也不增加逐命令审批页面。

## 6. 审计记录标签页

### 筛选与列表

筛选条件包括 Secret Key、目标连接、操作类型、时间范围和结果。列表分页展示，目录文件明细按需展开。

列表字段包括时间、Key 名称、连接、操作类型、命令或路径摘要、状态、耗时及详情入口。认证失败显示为未验证身份，不根据客户端自报名称伪装成已验证 Key。

需要覆盖的记录类型：命令、文件浏览 / 读取 / 写入、上传下载、任务查询与控制、Key 管理、授权或策略变更、服务启停、认证失败及审计清理。

结果需要清晰区分成功、Key 权限拒绝、被策略拦截、执行失败、请求取消、已取消、部分完成和中断 / 结果未知。活动操作还包括排队、等待用户、执行中、暂停。

### 操作与命中策略详情

- 操作 ID、关联任务 ID、发起 Key 的 ID 与当时名称。
- 当时的连接名称、主机、端口、账号和协议。
- 创建、开始、结束时间，耗时、实际结果与错误原因。
- 命令原文、可知退出码、超时 / 取消 / 输出截断状态；未知退出码不能显示成零。
- 命令原文使用可滚动、多行、只读查看块，支持选中和完整复制。
- 请求参数与结构化响应各自可查看和复制；命令响应支持 stdout / stderr 原文与 JSON 两种查看方式。
- 初始化、工具发现、ping 等归入“协议请求”类型；失败请求同样可查看已有参数和响应。
- 旧记录只显示已有摘要并注明未保存正文；进行中的请求注明响应尚未记录。文件正文省略及采集超限均有明确提示。
- 文件源与目标路径、读取范围或实际传输字节；目录任务展开逐文件结果。
- 生命周期时间线：排队、等待用户、执行、暂停、继续、取消、完成或中断。
- 被拦时展示匹配的策略名称、ID、版本、规则、实际动作和原因；多条命中可全部查看。
- 历史规则快照与当前策略明确区分，后续改名、编辑或停用不能改写当时的解释。

审计不采集认证请求头，认证字段隐藏，文件正文不保存；命令原文和 stdout/stderr 会保存。命令与输出可能含敏感数据，需要说明本地敏感数据属性，不能承诺已自动全部脱敏。

### 审计存储管理

- 提供保留周期、容量阈值与清理入口；具体数值按实现联调确定。
- 第一版不默认后台删除历史，达到容量阈值时提示处理并阻止启动新业务操作。
- 清理时明确范围和结果，活动、待核实和待恢复记录不在可清理范围。
- 审计写入失败显示独立故障；“操作已发生但结果未落盘”与“操作执行失败”使用不同描述。
- 故障期间仍提供本地停止服务和取消任务入口。

## 7. 关联任务详情

任务从审计记录进入，不依赖文件标签存在，也不需要另一个文件浏览页面。

- 任务 ID、原始操作 ID、所属 Key、连接、上传 / 下载方向。
- 本地与远端源 / 目标路径、冲突处理方式。
- 实际进度、已传输 / 总字节、逐文件成功 / 失败 / 跳过 / 被拦明细。
- 当前状态、错误原因、清理失败与已提交文件的说明。
- 按状态提供取消、暂停和人工继续；已撤销 Key、无授权或当前策略不允许时，不提供可成功继续的假象。
- “请求取消”与“已取消”分别展示；取消不会回滚已经提交的文件。
- 后台传输在客户端断开后继续；服务关闭或应用退出会收敛任务，重启后离线恢复且不自动继续。
- 命令第一版为同步单次执行，其超时 / 取消不能被描述为确认远端后台进程已经停止。

## 8. 必须覆盖的状态

| 类别 | 状态 |
|---|---|
| 空状态 | 服务未开启、暂无 Key、暂无策略、暂无审计、筛选无结果、目录明细为空 |
| 加载与反馈 | 列表加载、分页加载、保存中、复制成功、操作成功、字段错误、保存失败 |
| Key | 一次性密钥展示、从未使用、停用、撤销、变更未保存 |
| 策略 | SSH / 文件表单切换、无效正则、路径错误、缺少禁止操作、停用、收紧后任务受影响 |
| 拦截 | 命令被拦、来源或目标路径被拦、子项被拦导致部分完成、无法校验路径 |
| 等待用户 | 密码或私钥口令输入、主机指纹确认、交互认证；复用既有交互 |
| 服务故障 | 端口占用、监听失败、Key / 授权 / 策略存储失败导致停服 |
| 审计故障 | 容量达到阈值、开始记录失败、操作已发生但终态记录失败 |
| 任务结果 | 排队、执行、暂停、请求取消、已取消、成功、失败、被拦、部分完成、中断 / 未知 |
| 恢复 | 重启离线任务、Key 已撤销、当前策略禁止继续、检查点不可用 |

停用 / 撤销、关闭服务和审计清理涉及影响范围的交互，应说明具体后果。错误不以短暂成功提示覆盖，长路径、长命令和长错误需能查看完整必要信息。
