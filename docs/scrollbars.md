# 滚动条显隐统一

除顶部会话选项卡按最新要求始终隐藏滚动条外，应用内可控制的滚动区域使用 `uikit.Scrollbars`，复用既有 Scrollbar 令牌：滚动/偏移变化后保持显示700ms、显隐180ms过渡，鼠标进入滚动条边缘区域或拖动滚动条时保持显示。内容不溢出时不绘制滚动条；横向与纵向分别计算显隐状态，双轴预留交汇角。

## 真实终端后端差异（2026-11-02）

以上原型统一清单中的真实SSH正文现由MyGo原生VT View绘制。它不提供公开滚动状态/getter/setter，因此无法交给UIKit `Scrollbars`，这一消费者为**部分接入**；不能继续把旧演示文字Scroll的统一结果当作真实终端已验收。SDK提供原生历史滚动和自身滚动条，其余页面/表格/Modal仍用本清单的共享实现。没有通过私有接口、重建会话或伪造ScrollState隐藏差异。

## 实现与边界

- `Scrollbars(c, host, scroller, offset, props)`装饰原有Scroll/List节点，不在其数据行外新增父层；原生wheel、keyboard、惯性和List锚点继续由SDK处理。
- SDK原生thumb在自身clip恢复后绘制，所以用公开ScrollbarInsets将原生两轴thumb移出窗口，而非假定滚动节点自身裁剪能遮住它；自定义指示器不影响原生wheel/键盘/惯性。
- 滚动条与观察节点是非滚动frame中的绝对定位兄弟，避免随内容滚走；几何采用LayoutBounds，布局/range/offset变化仅请求必要的后续帧，不替换宿主原DrawOver。
- 会话选项卡使用SessionTabs自身的统一Input合并中键、拖动按下记录和纵向滚轮横移，原生横向wheel/触控板保留；不再构建自定义滚动条。仅在新建/选择时请求SDK ScrollIntoView，在布局后按新内容范围定位，不使用旧MaxX，也不在后续帧持续拉回用户滚动的位置。
- 新增标签且末尾标签被选中时，SessionTabs在选中标签的定位请求之后，补充尾部加号的ScrollIntoView，包含按钮完整宽度与前方间距；默认items路径及SSH/文件自定义BuildTabs路径共用。组合拆分保留的焦点在前方时，不以加号定位覆盖该焦点。BuildTabs返回原尾部按钮，不移动按钮或Drag源的父级。首次构建仅记录数量，保留恢复工作区的原活动标签定位；关闭、重排和普通滚动不触发尾部定位。
- 其他区域的边界wheel也能请求一次显示，旧独立终端显隐控制器不再并行运行。
- 滚动条轨道和thumb均KeepFocus，避免拖动指示器后抢走原输入/列表焦点。
- 快捷键表由普通列/行容器呈现，表头与数据共用固定比例（1/2、1/3、1/6）；内容自然撑高，只随设置页外层滚动。2026-11-02按用户后续要求移除内层滚动、双击适宽、拖动调宽及列重排。表格稳定Handle、动作Key、表格读屏角色、录制和恢复默认流程保留。
- UIKit只保存UI显隐时间和测量，不创建、销毁、重连SSH/File会话，不触碰持久化、网络、文件或钥匙串。
- 未新增测试、截图基线、组件画廊或CI；设备UI交互仍需单独验收，源码和Go检查不作为像素实测证据。
