# 会话弹窗与设置页

本轮按 `SSH-Tool-Session-Settings.zip/prompt.md` 实现 MyGo 原生界面，沿用项目固定的 MyGo v0.7.3、Go 1.27.3 与主题生成流程。

## 实现

- SSH 与 FTP/SFTP 两套新建弹窗复用编辑模式，顶部锚定，表单主体滚动，头部和底栏固定。覆盖认证切换、密码显示、私钥选择、分组新增、端口手改标记、失焦校验、首错聚焦、环境变量 chips、高级选项和键盘操作。
- 仅保存不会连接或高亮目录行；编辑保留原分组内的顺序。保存并连接始终新开选项卡；已有选项卡保留连接时的配置快照，标题随会话名称更新。
- 测试连接使用真实 SSH/FTP 协议，10 秒超时。SSH/SFTP 支持密码、托管私钥、agent 和 SSH 跳板；SFTP 额外请求子系统。FTP 支持显式/隐式 TLS、匿名、PASV/PORT（IPv6 使用 EPSV/EPRT）、NOOP/QUIT。TLS 使用系统证书校验。
- 测试未知 SSH 主机只报告 SHA256 指纹，不写 `known_hosts`；已变更/吊销的主机密钥失败。关闭或修改字段取消测试，后台只返回结果，UI 线程更新状态并通知读屏。
- 设置页进入、退出和分类切换均立即生效，不再使用页面淡入淡出或位移动画；同次打开时保留分类滚动位置；关闭后清理临时状态，保留上次分类。
- SSH、文件传输、设置在 Rail 右侧按当前活动页互斥构建，设置页显示时不构建其他工作区；会话状态和后台更新独立保留，选项卡与 Rail 保持可用。覆盖通用、外观、终端、文件传输、快捷键、密钥与凭据、关于，含搜索、分类滚动记忆、主题卡、强调色、配色网格、共享终端 renderer 的预览、字体/光标/回滚、快捷键录制及冲突替换。
- 三页导航重复选择当前页均保持原状态，设置入口与快捷键只进入，Esc 只处理控件或弹窗的取消。返回工作区聚焦原 SSH 窗格或活动文件面板；设置页中的工作区侧栏、监控按钮禁用，顶部会话标签的选择、关闭和恢复仍可用。原生设置菜单遵循弹窗的模态范围。连接、传输及已发起的分屏关闭均在隐藏时继续推进。
- 密钥可导入、生成 Ed25519/RSA 4096、重命名、复制公钥和移到系统废纸篓；引用中的密钥禁止删除。导入复制到应用目录，私钥权限 0600，口令使用系统钥匙串。生成和读写在后台进行，失败明确反馈。
- 配置写入 `App.Path(PathUserData)/sessions.json`、`prefs.json`，版本为 1；写临时文件后 rename。旧 catalog/terminal 偏好只读导入，读失败时阻止覆盖。密码仅在钥匙串，JSON 保存存在标记；目录写失败时补偿恢复原凭据。设置先即时生效，再防抖 300ms 写盘。

## 文档核对与组合实现

文档站无法访问时读取了官方 GitHub 的 [MyGo UI 文档](https://github.com/egoist/mygo/tree/main/docs/ui)、[native.md](https://github.com/egoist/mygo/blob/main/docs/native.md)、[i18n.md](https://github.com/egoist/mygo/blob/main/docs/i18n.md)，并以已安装 v0.7.3 源码核对。

- `DialogBase` 提供焦点陷阱和焦点交还；退出阶段保留节点，使用 token 动画后卸载。框架没有完整的弹窗退出时序，使用现有 Element 动画组合。
- `ui.Field` 无自定义标签列宽接口，使用行布局构造 72px 标签列，并向每个输入传递无障碍 Label 和错误 Description。
- `CollapsibleBase` 的 Trigger 保留键盘语义；其固定时长与要求不一致，用 token 的 180ms 进度组合裁切、高度、箭头和透明度。
- 应用减少动态效果通过统一解析处理自定义位移/缩放；内建控件仍服从系统的减少动态效果。颜色与透明度沿用 `AnimateColor`，避免框架将标量动画直接归零。
- 原生目录/密钥选择用 `mygo.Dialog.Open`；私钥与凭据用 `mygo.Secrets`，没有文件形式的凭据降级存储。

## 保留的原型边界与设计差异

- 本项目的工作区终端和文件传输仍为原有演示模型，没有真实 SSH PTY、屏幕模拟器和文件 I/O。真实协议只接入了「测试连接」。初始命令、环境变量、编码、Keepalive 等会话选项已保存；真实 shell 发送、窗口尺寸通知需要未来传输层消费，不能把当前演示日志当作真实连接验收。
- prompt §9 允许删减的「认证后添加到 agent」开关本轮不展示：当前工作区没有真实认证成功回调，避免提供不生效的选项；agent 检测与认证测试可用。
- SSH 与文件传输分别保存条目及分组，SSH 页只展示 SSH，文件页只展示 SFTP/FTP；分组以 `scope` 区分页面，允许两页各自保存同名分组。旧共享分组按条目原协议拆分，保留稳定 UUID、认证、高级选项及各页折叠状态。运行时 hostID 继续供拖放和会话引用使用，每站点本地路径改以 UUID 保存。
- 版本显示项目实际的 0.1.0 原型，没有使用设计稿虚构的 1.4.0。仓库未提供更新服务、发布说明或问题反馈地址，关于页明确说明，未伪造更新成功。
- 新设置页支持中英文，原有工作区与部分动态内容仍沿用中文；并非整个应用的完整英文翻译。
- 截图是 MyGo `ui.NewTester` 的软件渲染结果，使用独立演示配置，没有读取真实会话、钥匙串或网络。不是操作系统窗口截图，也不代表已经逐像素或人工完成全部原生交互验收。

## 输入框垂直居中修正

名称中文占位文字原先比正确居中位置低约 1.39px；等宽输入中的中文提示约低 1.42px。固定版本 MyGo 分别布局空文本与中文提示，却复用空文本的居中位置；两者自然行高不同造成偏移。

新增 `font.lineHeight.input`（18px），经 `C.Input.LineHeight`、`C.Search.LineHeight` 接入通用输入、会话输入、环境变量与三类搜索框；端口的非聚焦覆盖文字使用相同行高。原有 `font.lineHeight.body`（16px）不足以容纳此字号下的中文回退字体，因此没有修改正文行高。

隔离测量覆盖 UI/等宽字体、22/24/28px 控件、中英文占位/输入、密码与环境变量，共 48 个组合，18px 行高使占位文字的居中位置误差归零，并保持已有实际输入文字的基线。现有测试、构建、vet 与差异检查通过；未新增永久测试或进行整页视觉验收。

## 设置页关闭清理
