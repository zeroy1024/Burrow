# 界面语言

应用完整提供简体中文、English 和跟随系统。语言选择保存到现有应用偏好；界面使用 MyGo 的单一语言状态。跟随系统会从应用支持的语言中匹配系统偏好，无法匹配时使用源语言简体中文。

## 资源与生成

`internal/locales/zh-Hans.json` 是完整源资源，`en.json` 提供对应英文。资源采用 MyGo 的 ARB/ICU MessageFormat，`mygo.json` 声明目录和源语言。MyGo 同时接入所需的内建控件及菜单翻译。

```sh
mise run i18n
```

此任务生成 `catalog_gen.go`，校验消息语法、参数和复数规则，再检查英文覆盖、printf 参数一致性及源代码遗漏文案。生成文件与 JSON 一起提交，普通 `go build` 和 `go test` 不需要预先运行生成器。GitHub 和 Gitea CI 均检查生成结果是否同步。

新增文案使用稳定的英文语义标识，通过生成函数调用。已有迁移文案按 `message` 前缀组织，公共、页面和数量消息使用对应前缀。修改显示文字不应修改消息标识。需要数量变化的句子使用 ICU 复数消息，参数类型在源资源的 `@消息标识.placeholders` 中声明。避免将句子拆成多个翻译片段，也不要翻译完成后再拼接数量。

## 动态提示与状态

每帧构建的界面直接调用资源函数。需要跨帧保存的错误、通知和测试结果使用 `locales.Text` 保留消息函数及参数，在展示时调用 `String()`；清除提示使用其零值。`Deferred` 保存无参消息，`Format` 保存现有 printf 模板及参数，`ErrorText` 保留原始错误对象。`Raw` 用于用户内容、远端输出或已保存的历史原文。

应用自有错误使用 `locales.NewError` 或 `locales.Errorf`，后者保留 `%w` 错误链。不要为了翻译丢失 `errors.Is`、`errors.As` 所需的原始错误，也不要对用户文本或完整错误详情做通用字符串替换。系统和第三方返回的诊断详情保留原文。

语言切换会更新自定义菜单并刷新 MCP 的展示快照，不重新连接 SSH、不重启 MCP，也不改变授权、筛选值和任务状态。MCP 工具名、动作、状态码和持久化字段使用稳定标识；时间线和状态标识在界面展示时翻译。日期显示结合应用语言与系统区域格式，存储时间不变。

## 内容边界与验证

主机和分组名称、路径、命令、终端输出、主题名称、公钥、指纹、协议标识和许可证正文保留原文。已有示例分组名称也是可编辑目录数据。设置中保留双语搜索关键词，语言检查脚本只对这些明确的数据位置作豁免。

历史审计和传输记录中的自由文本保留记录时的语言；不会重写既有数据库。应用当前提示和状态采用当前语言。原生系统对话框的部分系统文案受平台限制，可能在下次启动后才使用应用语言。

资源检查、已有测试和编译不能代替原生界面验收。中英文在最小窗口下的换行、截断、读屏表现和系统对话框应单独记录验收结果。
