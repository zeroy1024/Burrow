# Interface languages

[English](i18n.md) | [简体中文](i18n.zh.md)

The app provides English, Simplified Chinese, and System. The selection is saved in existing app preferences and uses MyGo's single language state. System matches the user's preferred languages against the app's supported languages and falls back to the source language, Simplified Chinese, if none match. This app resource source is independent of the documentation convention: default `.md` documents are English, with Chinese in `.zh.md`.

## Resources and generation

`internal/locales/zh-Hans.json` is the complete source catalog; `en.json` supplies English. Resources use MyGo's ARB/ICU MessageFormat. `mygo.json` declares their directory and source language. MyGo also links the required translations for its built-in controls and menus.

```sh
mise run i18n
```

This generates `catalog_gen.go`, validates message syntax, arguments, and plural rules, then checks English coverage, printf argument consistency, and missed source literals. Commit generated Go with the JSON files. Ordinary `go build` and `go test` do not require a separate generation step. GitHub and Gitea CI check that generated output is current.

New messages use stable English semantic IDs and generated functions. Migrated messages use the `message` prefix; common, page, and count messages use their corresponding prefixes. Copy edits should not change IDs. Use ICU plural messages for count-dependent sentences and declare parameter types under `@messageId.placeholders` in the source catalog. Keep sentences whole instead of joining translated fragments or adding a count afterward.

## Dynamic messages and state

UI rebuilt each frame calls resource functions directly. Errors, notices, and test results retained across frames use `locales.Text` to retain message functions and arguments, then call `String()` when displayed. Its zero value clears a notice. `Deferred` stores a message without arguments, `Format` retains an existing printf template and arguments, and `ErrorText` retains the original error object. `Raw` is for user content, remote output, or saved historical text.

App-owned errors use `locales.NewError` or `locales.Errorf`; the latter preserves `%w` chains. Keep the original error needed by `errors.Is` and `errors.As`. Do not translate arbitrary user strings or entire error details through generic text replacement. System and third-party diagnostics retain their original content.

A language change updates custom menus and refreshes MCP presentation snapshots without reconnecting SSH, restarting MCP, or changing grants, filter values, or task state. MCP tool names, actions, state codes, and persisted fields use stable identifiers. Timeline and status identifiers are translated at display time. Date display combines the app language with system regional formats; stored times are unchanged.

## Content boundaries and validation

Host/group names, paths, commands, terminal output, theme names, public keys, fingerprints, protocol identifiers, and license texts retain their original content. Existing sample group names are also editable catalog data. Settings retains bilingual search terms; the language checker exempts only their explicit data locations.

Free text in historical audit and transfer records stays in its recorded language; existing databases are not rewritten. Current app messages and statuses use the current language. Some native system dialog text may use the app language only after restarting, subject to platform behavior.

Resource checks, existing tests, and compilation do not replace native UI acceptance. Record wrapping, truncation, accessibility, and system dialog behavior in both languages at the minimum window size separately.
