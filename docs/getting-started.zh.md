# 首次使用

[English](getting-started.md) | [简体中文](getting-started.zh.md)

## 运行应用

macOS 运行基线为 13 及以上系统；Windows 的构建入口和原生运行验收范围见[平台支持](platform-support.zh.md)。从源码启动、生成应用包的步骤见[开发与构建](development.zh.md)。

首次启动没有预置主机或文件站点。应用提供 SSH、文件传输、网关、MCP 和设置页面；切换页面会保留已经建立的连接和后台传输。

在「设置 → 通用 → 语言」中可选择简体中文、English 或跟随系统，切换即时生效。连接、传输和表单状态不会因切换语言而重置；系统或远端返回的原始诊断、用户输入和历史自由文本保留原文。详见[界面语言](i18n.zh.md)。

## 建立第一个 SSH 会话

1. 进入 SSH 页面，使用添加入口或 `⌘N` 新建会话。
2. 填写名称、主机地址、端口和用户名，选择密码、私钥或 SSH agent 认证。需要时可在表单中新增分组。
3. 可先选择「测试连接」检查认证与服务器可达性，再选择「保存」或「保存并连接」。测试也会实际访问服务器，并遵循正式连接的主机信任规则。
4. 首次遇到未知主机密钥时，核对服务器指纹后决定是否信任。主机密钥变更或被撤销时，连接会被拒绝。
5. 连接成功后在终端输入命令。只保存的条目可通过侧栏双击打开。

侧栏单击只聚焦条目，双击新开会话。同一条目可以打开多个独立会话。认证、高级选项与凭据管理见[会话与设置](session-settings.zh.md)。

## 使用分屏与标签

- 选中一个已连接的 SSH 窗格，使用分栏按钮或 `⌘D` 创建独立 Shell；这些 Shell 复用同一 SSH 连接。
- 拖动窗格或标签调整组合；移动已有窗格保留其终端与连接。
- 使用窗格上的放大按钮切换单窗格展示，关闭按钮结束对应窗格。
- `⌘1` 至 `⌘4` 在多分屏时优先切换窗格；`Ctrl+Tab` 和 `Ctrl+Shift+Tab` 始终切换标签。

关闭一个 Shell 不会关闭同一连接上的其他 Shell。更多快捷键见[会话与设置](session-settings.zh.md#默认快捷键)。

## 打开文件站点

1. 切换到文件传输页面，新建 FTP/SFTP 会话。
2. 选择 SFTP 或 FTP。SFTP 使用 SSH 认证；FTP 按服务器要求设置 TLS、主动或被动模式以及文件名编码。
3. 填写本地和远程初始目录，保存并连接。
4. 在双面板之间拖动文件或目录，开始上传或下载；在底部传输栏查看和管理当前标签的任务。

SSH 与文件页的保存目录各自独立。即使名称和地址相同，也不会自动同步编辑或删除。任务暂停、重名选择及退出恢复见[文件管理与传输](file-transfer.zh.md)。

## 关闭与恢复

默认点击主窗口的关闭按钮会退出应用：保存工作区与设置、停止 MCP 服务、暂停并保存传输任务，然后关闭所有会话连接。macOS、Windows 和 Linux 使用相同行为。关闭最后一个标签的行为可在设置中单独选择。

在「设置 → 通用 → 后台运行」中，可选择关闭主窗口时退出或后台运行。后台运行只隐藏窗口，已启用的 MCP、连接和传输继续运行，当前凭据保持解锁。菜单栏／托盘图标默认显示，选择关闭窗口即退出时可隐藏；后台运行时必须保留图标。点击图标可打开 Burrow、查看及启停 MCP、打开设置或退出。再次启动 Burrow 会唤醒已有窗口；认证请求需要用户输入时会显示窗口。Linux 托盘需要 `libayatana-appindicator3` 及支持 AppIndicator 的桌面面板；创建图标失败时会报告错误并保留窗口入口。

macOS 另有两个独立开关，默认均关闭：「隐藏程序坞图标」会在主窗口转入后台后隐藏 Dock 图标，重新打开窗口时恢复；「⌘Q 仅关闭窗口」让 Cmd+Q 只隐藏主窗口，Burrow 保留在菜单栏，已启用的 MCP、连接与传输继续运行。开启后者时，无论窗口关闭行为如何配置，都必须保留菜单栏图标；应用菜单会显示带 Cmd+Q 快捷键的「后台运行」。这两个开关不在 Windows 或 Linux 显示。

应用和托盘菜单中的「退出」始终会完全退出，包括窗口隐藏时，并收敛连接和传输、保存状态；默认 Cmd+Q 也执行同一退出流程。开启「启动时恢复会话」后，下次启动恢复工作区及可关联的任务，保持离线；需要手动连接或继续传输。

出现连接、续传或监控不可用时，先查看实际错误与[已知限制](limitations.zh.md)。
