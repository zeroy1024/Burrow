授权密钥弹窗 · 设计草图

MCP → 授权密钥

相对现有实现的主要调整

  1. 去掉「第 N 段」徽章：表单不是分步向导，编号没有信息量。改为小标题加一行说明，分区之间只靠留白区分，页面上的蓝色块从 3 条整宽色带减到 0。
  2. 名称字段：标签放在上方，提示放在下方，输入框占满整行，不再和右侧提示挤在同一行。校验出错时，错误信息替换提示行。
  3. 权限矩阵合成一张表：外面只有一个边框，行间用分隔线，不再每行一张卡片，表头也不再单独做一块底色。开关换成复选框，能力列从 118px 收到 76px，连接列不再被截断；「合并 2 条配置」从副标题里拆出来，做成徽章。
  4. 提示跟着状态出现：「默认不授予权限」写进小标题说明，不再用橙色。SFTP 和命令执行的说明放在表格下方；勾选任意「命令执行」后，这条说明变成警告样式并显示连接数。行级警告（连接变更、合并配置）在该行下方完整换行显示。
  5. 汇总计数：小标题右侧显示「已授权 n / N 个连接」，不用逐行去数开关。
  6. 本地目录改成上下两组：每组一行标题、含义和「添加目录」，空状态收成「未添加」徽章。两组都要说的「仍受文件策略限制」只写一次，放在小标题说明里，同时写明「未添加则拒绝该方向的传输」（对应 AuthorizeLocal 现有行为）。
  7. 层级收敛：容器只剩弹窗底色、分组框、目录条目三层。颜色只用在强调色（勾选、添加）和警告上。
  8. 条目多时：弹窗高度封顶，标题和底栏固定，只有正文滚动，正文滚动后标题下方出现分隔线。权限表头在表格范围内吸顶，滚到中间也能看到列名。连接数超过 8 个时显示搜索和「仅看已授权」；开启筛选时记下当时已授权的连接，所以取消勾选后该行不会立刻消失。顶部可以切到「表格内滚动」，对比备选方案。

落地到 MyGo 时涉及的改动

  • mcpKeyModal：去掉三个 uikit.Badge 段标题，改用 Text 组成小标题和说明；名称改为标签在上的 FormRow。
  • PermissionMatrix：外层改成单个分组框加行分隔线；单元格的 Switch 换成 Checkbox；size.mcpPermissionColumn 从 118 改为 76；Warning 改为单独的换行行。需改动
  • 合并数目前拼在 Subtitle 里（mcpGrants），需要拆成独立字段，直接取 len(Sources) 即可。需改动
  • 命令执行警告只根据 draft.Grants 里 AllowExec 的数量显示，不涉及后端。
  • DirectoryListEditor：改为纵向的「标题行 + 列表」布局，两处调用放进同一个分组框。
  • 吸顶表头：弹窗正文目前是 ui.Scroll，不支持吸顶。MyGo 的 ui.List 支持吸顶表头（ListState.Header），需要把正文改成 List，或者自己实现表头固定。需改动
  • 表格内滚动（备选）：给表格行区域单独套一个 ui.Scroll 并设最大高度，实现最简单，代价是弹窗里会出现滚动嵌套。
  • 搜索与筛选只在界面层过滤 draft.Grants，不涉及后端；显示阈值 8 是占位值，需要按常见窗口高度确定。待确认
  • 编辑模式：副标题从 EditingID 改为前缀和创建时间（mcpSecretKey 已有 Prefix、CreatedAt）；底部「明文仅创建时显示」的提示只在新增时显示。待确认
