相对现有实现的主要调整

  1. 主从布局：左侧沿用「远程会话」侧栏的分组列表（SSH 网关 / SOCKS5 代理、搜索、底部计数），右侧显示选中网关详情；页面不再只是一张卡片里的平铺列表。
  2. 默认出口放到顶栏：与 MCP 页顶栏同构，直接显示默认出口的实际路径和「跟随默认」的会话数，切换默认不用再找表单行。
  3. 连接路径可视化：本机 → 上游 → 本网关 → 目标主机，多级网关一目了然；上游节点和配置中的上游都可点击跳转。
  4. 测试结果内联：不再弹窗。测试时连线流动，只走到本网关为止，与实际测试范围一致（不访问目标主机）。tokyo-edge 演示失败态。
  5. 引用分组可见：应用设置、主机与站点、下游网关、运行中四类分组列出；删除确认直接列出需要解除的引用。
  6. 编辑弹窗：类型使用卡片式分段（同会话弹窗的协议选择）；SOCKS5 地址与端口同行，认证显式二选一；上游选项禁用会成环的网关，并实时预览路径。
